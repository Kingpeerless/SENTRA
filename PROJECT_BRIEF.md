# SENTRA — Project Brief

## Overview

**SENTRA** is AI Agent Security Infrastructure: a security gateway for autonomous AI agents that evaluates proposed financial transactions before authorization.

**Tagline:** AI can act. SENTRA keeps it accountable.

**Positioning:** Trust is not assumed. It is enforced.

## Purpose

SENTRA evaluates proposed agent transactions and produces deterministic **ALLOW**, **WARN**, or **BLOCK** decisions before authorization. It is designed to make agent activity governed, reviewable, and accountable.

## Core Capabilities

- **Agent Registry** — Register and manage autonomous agents.
- **Deterministic Policy Engine** — Evaluate proposed transactions against deterministic policies.
- **Transaction Firewall** — Apply security decisions before a transaction is authorized.
- **Human Approval Center** — Provide a place for human review and approval.
- **Threat Lab** — Test agents against malicious or manipulated instructions.
- **Audit Trail** — Record activity and decisions for review.

## Security Principles

1. AI must never override a deterministic **BLOCK** decision.
2. Never expose unrestricted private keys to an AI agent or LLM.
3. Keep simulations separate from real blockchain transactions.
4. Clearly distinguish implemented features from planned features.
